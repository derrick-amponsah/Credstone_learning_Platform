A labelled text box for short answers, search terms and sign-in details.

The consumer provides a visible label, optional hint text and, on error, a message that says how to fix the problem. Always pair `cs-input` with a `cs-label` using `for`/`id`.

Do not use placeholder text as the label. Do not signal an error with the red border alone: show `cs-error` with an icon and a sentence.
