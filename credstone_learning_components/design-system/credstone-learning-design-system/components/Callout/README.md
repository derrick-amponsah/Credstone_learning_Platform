A short message set apart from the surrounding text. Use `cs-callout` (`highlight` fill) for a reminder or key point inside a lesson, with a bold lead word such as "Remember." Use `cs-feedback` (`success-bg` fill) with a check icon for a correct answer.

The consumer provides one or two sentences. Start with a bold lead word, keep it under 30 words and place it directly after the content it refers to. A wrong-answer message uses a `cs-callout` with an explanation and a hint, never red.

Do not use more than one callout in a row, and do not rely on the green fill alone: include the check icon and the words "That's right."
