A card that presents one course: a tag, a serif title, a meta line and either a progress bar or a link. Use `cs-card` for grid cards and add `cs-card--feature` for the single "Continue where you left off" card.

The consumer provides the course title, number of lessons, duration and either a percentage or an action link ("Start course", "View course"). Required courses always lead with a `cs-tag--required` tag that includes the due date. Lay cards in a grid with `space-5` gaps and let the grid wrap to one column on phones.

Do not add shadows, coloured left borders or images; the card is defined by its `border` and `radius-lg`.
