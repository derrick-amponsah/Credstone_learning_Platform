A button for the one action a learner should take next. Use `cs-btn--primary` (gold) once per view for the main action, `cs-btn--secondary` (outlined navy) for supporting actions and `cs-btn--text` for low-priority links such as "Show a hint".

The consumer provides a clear verb label ("Continue lesson", "Check my answer"). Buttons are at least `touch-min` high and the primary is `touch-primary` high. On a `navy` ground wrap the group in `cs-on-navy` so the outline and focus ring use the on-navy tokens.

Do not put two primary buttons side by side, set button text in gold on a light ground, or use a button label shorter than a verb.
