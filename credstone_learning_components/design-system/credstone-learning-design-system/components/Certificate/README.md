A printable certificate sheet awarded when a learner completes a course. Use `cs-cert` for the sheet and `cs-cert__inner` for the double gold frame; centre the content on one column.

The consumer provides the learner's name, the course title and the award date, and sets the organisation name in the last line. Use the `display` style for the name, `cs-cert__course` for the course and `cs-eyebrow` for the heading. Place "Download certificate" (primary) and "Share or print" (secondary) beside the sheet, not inside it.

The gold frame is decorative; the name and course carry the meaning. Do not add logos you were not given, signatures or seals drawn from memory.
