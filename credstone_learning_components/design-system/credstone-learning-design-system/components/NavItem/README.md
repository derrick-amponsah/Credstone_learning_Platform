The desktop sidebar and its navigation items. Use `cs-nav` as the `navy` container, one `cs-nav__item` per destination and `cs-nav__item--active` for the current page. Always set the container in `cs-on-navy` so focus rings use `focus-on-navy`.

The consumer provides five or fewer destinations, each with a 24px stroke icon and a text label: Home, My Courses, Calendar, Certificates, Help. On phones replace the sidebar with a `navy` bottom tab bar of four items with 13px labels.

Do not show icon-only items, and do not add a sixth destination without removing one.
