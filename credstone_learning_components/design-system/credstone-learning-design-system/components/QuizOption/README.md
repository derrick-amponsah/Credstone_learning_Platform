A full-width answer choice for a quiz question. Wrap options in a `fieldset` whose `legend` is the question in the `title` style, and make each option a `label.cs-option` containing a real radio input. Add `cs-option--selected` to the chosen option: it gets a `navy` border, `highlight` fill and bold text.

The consumer provides the question, three to four answers and a shared `name`. Each option is at least `touch-option` high and the whole row is clickable. Show feedback in a Callout below the group after the learner checks their answer.

Do not mark the right answer with colour alone, hide the radio input, or use more than four options.
