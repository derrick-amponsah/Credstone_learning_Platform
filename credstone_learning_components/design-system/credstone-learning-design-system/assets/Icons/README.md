# Icons

84 line icons on a 24px grid with a 1.8px stroke, round caps and joins. Each file is a single ink, `#111E38` (navy), because pictures loaded with `<img>` cannot inherit `currentColor`.

For a different colour, inline the SVG markup and set `stroke="currentColor"` (every `Button`, `NavItem` and `Alert` preview does this). Use 20px beside small text, 24px by default and 32px in feature tiles. Always put a word beside an icon that starts navigation.
