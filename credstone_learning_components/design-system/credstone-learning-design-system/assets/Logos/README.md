# Logos

The Credstone mark is a gold "C" arc around a sand block on a navy square. Use `credstone-mark.svg` on light grounds and `credstone-mark-on-dark.svg` on `navy`. `credstone-wordmark*.svg` pairs it with the name set in Source Serif 4 Bold; if the font is not installed the file falls back to Georgia, so set the name as live text in the product. `credstone-app-icon.svg` is the 512px store icon and `credstone-favicon.svg` the browser tab icon. Keep clear space equal to the height of the sand block on all sides; never recolour, stretch or add effects.
